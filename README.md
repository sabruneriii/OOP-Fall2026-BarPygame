### Project info:
Title: Virgin Bartending Game Using Pygame 

Major: Computer Science 

Department: Computer Science 

 

This project serves as a proof of concept for a two-dimensional, single-player bartending video game developed in Python 3 using the Pygame library. The game is designed as a virgin bartending experience in which the player receives drink orders from a variety of non-player characters (NPCs) and fulfills those orders by completing several interactive minigames. Players will have a limited amount of time to complete as many orders as possible, with their score determined by both the number of drinks completed and the accuracy or quality of their preparation. 

Planned features include three functional minigames, a main menu, a settings system, a scoring system, a local high-score board, a tutorial, and an introductory playable level. The game will also incorporate two background music tracks, sound effects for various gameplay interactions, and placeholder artwork. At least three different drinks and three NPCs will be included in the initial implementation. NPC and drink information will be stored in external text files, allowing new characters and recipes to be added or modified without requiring major changes to the game source code. This modular approach is intended to make the project easier to expand while demonstrating the feasibility of the larger game concept.
